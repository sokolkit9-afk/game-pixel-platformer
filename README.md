# Pixel Runner

Двухмерный платформер на Godot 4.7. Вся графика и звук — бесплатные ассеты
Kenney под лицензией **CC0** (public domain, можно использовать в коммерческих
проектах без указания авторства). Интерфейс полностью на русском языке.

## Запуск

Нужен Godot 4.7 (подойдёт и 4.4+).

```bash
# из редактора
godot --path . --editor

# сразу играть
godot --path .
```

Или откройте папку проекта через «Импорт» в Godot Project Manager.

Игра стартует с главного меню, а не сразу с уровня.

## Управление

| Клавиши | Действие |
|---|---|
| `←` `→` или `A` `D` | бег |
| `Space`, `W`, `↑` | прыжок (чем короче нажатие, тем ниже прыжок) |
| `Esc` | пауза и меню |
| `R` | начать уровень заново |

В меню и на экранах паузы/итогов работает мышь и клавиатура: `↑` `↓` — выбор,
`Enter` — нажать.

## Что в игре

- **Главное меню**: заголовок на фоне игрового пейзажа, кнопки ИГРАТЬ /
  УПРАВЛЕНИЕ / ВЫХОД и отдельный экран с подсказками по управлению.
- **Пауза** (`Esc`) — панель с кнопками ПРОДОЛЖИТЬ / НАЧАТЬ ЗАНОВО / В ГЛАВНОЕ МЕНЮ.
  Мир на паузе замирает, интерфейс продолжает работать.
- Уровень 100 × 14 тайлов (1800 × 252 px) с ямами, парящими платформами и уклоном вверх к финишу.
- **Монеты** (+10), **самоцветы** (+50), **сердца** (+1 жизнь).
- Два вида врагов: **ходоки** патрулируют платформу и разворачиваются у стены и на краю,
  **летуны** качаются в воздухе по синусоиде.
- Прыжок врагу на голову убивает его (+100 и отскок), касание сбоку — убивает игрока.
- Падение в яму смертельно. 3 жизни, затем экран ИГРА ОКОНЧЕНА.
- HUD: счёт монетами и самоцветами тайлами-цифрами, жизни — сердечками,
  подсказка по управлению внизу экрана в первые секунды уровня.
- Параллакс облаков, «coyote time» и буфер прыжка — управление не «съедает» нажатия.

## Как править уровень

Уровень — это текстовая карта в `scripts/level.gd` (константа `MAP`).
Один символ = один тайл 18 × 18:

| Символ | Значение |
|---|---|
| `#` | твёрдый блок (трава сверху, земля внутри — расставляется само) |
| `.` | пустота |
| `P` | старт игрока |
| `G` | финиш |
| `o` `*` `+` | монета, самоцвет, сердце |
| `e` `f` | ходок, летун |
| `b` `m` `c` `t` `s` `n` `k` `r` | декор: куст, гриб, кактус, ёлка, табличка, забор, ящик, бочка |

Коллизия собирается горизонтальными полосами, поэтому сотни блоков не превращаются
в сотни шейпов. Ширина строк может отличаться — строки дополняются точками.

Посмотреть, что получилось, можно не открывая движок:

```bash
pip install Pillow
python tools/render_preview.py     # preview/level.png и три кадра по 360×180
```

## Тест

Дымовой тест поднимает главную сцену, прокручивает физику и проверяет, что игрок
приземляется, прыгает, бежит, собирает предметы и доходит до флага:

```bash
godot --headless --path . res://tests/SmokeTest.tscn
```

Возвращает код 0, если всё в порядке, и 1 со списком провалов иначе.

Захват кадров интерфейса (нужно окно, в headless не рендерит):

```bash
godot --path . res://tests/CaptureUi.tscn
```

Складывает в `preview/` пять картинок 1080 × 540: меню, экран управления,
игру, паузу и экран победы. Это самый быстрый способ проверить, что вёрстка
интерфейса не разъехалась.

## Что стоит знать

- **Тайлы земли — колонка 2 тайлсета.** Только там тайлы полностью непрозрачны и
  стыкуются сами с собой без швов: `(2, 0)` — трава, `(2, 6)` — почва. Остальные
  колонки дают видимую сетку или прозрачные углы. Координаты — в `scripts/tiles.gd`.
- **Земля рисуется по спрайту на клетку.** В `level.gd::_build_terrain()` спрайт
  ставится в цикле `for i in run`, а не один раз на всю полосу: иначе земля
  выглядит узкими столбиками с дырами. Коллизия при этом одна на всю полосу.
- **Кириллица — через Tiny5.** Встроенный шрифт Godot не содержит русских букв.
  Tiny5 — пиксельный шрифт с полным набором кириллицы, он подключается один раз
  в `ui_theme.gd` и раздаётся всем `Control` через `Theme.default_font`.
- **Панели интерфейса центрируются якорями.** В `overlay.gd` и `menu.gd` панель
  получает якоря 0.5 с нулевыми offsets и `GROW_DIRECTION_BOTH` — тогда её размер
  считает движок, и не нужно угадывать, когда контейнер посчитал `min size`.
  Попытка выставить `position` до `add_child()` даёт сдвиг: offsets считаются
  от нулевого размера родителя.
- **Флаг финиша нарисован вектором** (`Polygon2D` в `goal.gd`): подходящего
  треугольника в тайлсете нет.
- **Буква «Й» в Tiny5** рисуется с отрывом бревиса от буквы — это особенность
  шрифта, а не баг вёрстки.
- Звук в headless-режиме не воспроизводится, но и не мешает — `AudioStreamPlayer`
  просто не выводит сигнал.
